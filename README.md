# Collision Map

A RuneLite plugin that visualizes collision data in Old School RuneScape.

## Features

- **Blocked tile visualization:** Highlights tiles that cannot be traversed.
- **Directional wall visualization:** Displays north, south, east, and west collision boundaries.
- **Configurable colors:** Customize the colors and transparency of blocked tiles and walls.
- **Independent visibility controls:** Toggle blocked tiles and walls separately.
- **Wall thickness:** Adjust the thickness of the wall indicators.

## Configuration

Open the RuneLite configuration panel, search for **Collision Map**, and customize the visualization settings.
